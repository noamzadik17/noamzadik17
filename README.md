| Project | Focus | Stack | Highlights |

| **VI // Archive** | Interactive 2D/3D WebGL2 map & archive | `Next.js` `TypeScript` `Tailwind CSS` `WebGL2` `Framer Motion` | 3,431 landmarks & 127-item 100% completion tracker — [Live](https://grandtheftauto-kohl.vercel.app) |
| **ERD Planner** | Zero-dependency bilingual ERD studio | `JavaScript` `HTML5 Canvas` `SQL` `DBML` `Mermaid` | EN/HE RTL support, multi-dialect SQL import, and 6 export formats |
